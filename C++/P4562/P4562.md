# 题解
-------------
对于任意的$l$和$r$,我们将这个区间中的所有数字分为两类,以$4-8$作为例子,   
$4,5,6,7,8$,其中的$4,5,6,7,$把它们全部经过之后就可以完成巡逻,所以我们的任务关键就是找到这些关键点.   
我们可以用一个时间复杂度为$O(n)$的筛法完成这一个处理   
对于任意的非关键点,因为我们有k个关键点,将整个序列分成了k+1段,那么它在所有关键的后边的概率为
$$P=\frac{1}{k+1}$$
但是整个序列有$n-k$个非关键点,所以排在所有关键点后面的非关键点数量的期望是
$$E=(n-k)*P=\frac{n-k}{k+1}$$
所以最后一个关键点的位置的期望就是
$$E=n-\frac{n-k}{k+1}=\frac{nk+n-n+k}{k+1}=\frac{k(n+1)}{k+1}$$
这就是对于每个序列对于答案的贡献的期望,我们总共有$n!$个序列,所以我们的答案就是
$$\frac{k}{k+1}(n+1)!$$
对于代码就是,
1. 用筛法求出所有的关键点数量$k$
2. 求出$k+1$的逆元
3. 依次计算即可,注意开$long~long$
